# POWERFARM Layout System

The layout system turns the brand ingredients into repeatable compositions.

## Core behavior

POWERFARM layouts should feel **structured, spacious, engineered, and decisive**.

A page should normally have:
1. one dominant visual idea
2. one obvious reading order
3. clear grid alignment
4. enough negative space for the content to breathe

## Grid

### Desktop
- 12 columns
- 24 px gutters
- 64 px outer margins
- 1440 px recommended max content width

### Tablet
- 8 columns
- 20 px gutters
- 40 px outer margins

### Mobile
- 4 columns
- 16 px gutters
- 20 px outer margins

### Presentation
- 12 columns
- 20 px gutters
- 60 px outer margins

### Print / report
- 6 columns
- 18 px gutters
- 42 px outer margins

## Composition rules

- Left alignment is the default.
- Use controlled asymmetry rather than centering every element.
- Hero text should typically occupy 30–40% of the composition.
- Use 5/7 or 7/5 splits for text + image.
- Use diagonals as transitions or crops, not as decoration everywhere.
- Keep amber accents small and purposeful.
- Cards inherit the page grid.
- Dense imagery should never sit directly behind the main logo.
- Crop oversized typography only when the word remains instantly legible.
- Do not combine multiple patterns, large icons, diagonal bands, and oversized type in one small area.
