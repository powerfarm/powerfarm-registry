# POWERFARM Photography + Generative Image Direction

This package defines how POWERFARM imagery should look across photography, AI-generated imagery, campaigns, websites, presentations, reports, and motion keyframes.

## What to use first

Start with `powerfarm-imagery-genesis-prompt.md`.

Then add one recipe from `powerfarm-universal-prompt-library.md`.

Use `powerfarm-negative-constraints.md` to stop a model from drifting into generic stock, cyberpunk, fantasy energy, or implausible engineering.

## Why this system is model-agnostic

The prompts contain:
- subject
- mood
- composition
- lighting
- realism
- color discipline
- exclusions
- intended use

They intentionally do **not** contain platform-specific flags, model names, sampler settings, or proprietary syntax.

## Image hierarchy

1. Real photography, when available and credible
2. Generative imagery that looks photographically plausible
3. Abstract generative campaign imagery
4. Illustration only when the communication problem benefits from it

## Golden rule

POWERFARM imagery should look **advanced because the engineering is excellent**, not because the picture is full of futuristic effects.
