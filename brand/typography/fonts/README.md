Binary font files are intentionally not included in this GitHub-ready package. The canonical license texts remain under `../licenses/`.

The generated brand CSS resolves `Anton` and `Inter` through local font lookup and then falls back to the canonical typography stacks. An internal release that restores separately managed binary font assets may use its own asset pipeline without changing the semantic typography tokens.
