<!-- POWERFARM-MAP:END -->

Report Registry vulnerabilities privately through GitHub Security Advisories. Do not publish issues containing credentials or exploitable identity, Office/Occupancy, key, OAuth, Store, or control-plane details.

Never commit production credentials, private signing keys, service-role secrets, live session cookies, or live `.env` files. Registry runtime tokens are short-lived operational credentials and do not create institutional Authority.
