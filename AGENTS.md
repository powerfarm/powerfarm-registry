For an LLM or coding agent entering this repository:

1. Read `README.md` and `DOCUMENTATION.md` first.
2. Read `docs/AUTHORITY-EXTRACTION.md` before changing identity, OAuth, Store or runtime boundaries.
3. Registry owns Identity, Office/Occupancy, keys, Brand, Store/Gadgets, Manifest and exact artifact lineage.
4. Registry does not own institutional Authority, RunGrants, Process admission, execution consequence, Cards or Heartime circulation.
5. Treat workspace owner/editor/operator roles as Registry-local product ACLs only.
6. Never mint institutional Authority from credentials, capabilities, occupancy or product roles.
7. Run `npm test` and `npm run github:check` before completion.
